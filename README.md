# HR Analytics Dashboard — Tableau

## Project Overview
An interactive HR analytics project built using Tableau to analyze employee hiring, workforce demographics, salary distributions, and employee information.

## Dashboard Sections
- **Overview:** Hiring trends, active employees, terminated employees, and department headcount.
- **Demographics:** Gender, age group, education, and department analysis.
- **Income Analysis:** Salary analysis by department, position, gender, and education.
- **Employee Directory:** Employee details with interactive filters.

## Tools Used
- Tableau
- Data visualization
- Calculated fields
